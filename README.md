# Juber_app_mobilidade
## Projeto que visa o transporte compartilhado de estudante universitários para faculdade

Juber

Juber é um projeto acadêmico de aplicativo de transporte compartilhado para estudantes universitários, desenvolvido com o objetivo de facilitar o deslocamento até a faculdade por meio da conexão entre estudantes que realizam trajetos semelhantes.

A proposta surgiu a partir de um problema comum na rotina universitária: estudantes que enfrentam dificuldades com transporte, horários, custos elevados e trajetos pouco convenientes para chegar à instituição de ensino.

### Objetivo do projeto

O principal objetivo do Juber é criar uma solução que permita aos estudantes compartilhar trajetos até a faculdade, conectando passageiros e motoristas de maneira organizada.

A aplicação busca:

Facilitar o deslocamento dos estudantes;

Reduzir os custos relacionados ao transporte;

Aproveitar vagas disponíveis em veículos que já realizariam determinado trajeto;

Conectar estudantes que possuem rotas semelhantes;

Proporcionar uma alternativa mais prática ao transporte individual;

Incentivar o compartilhamento de veículos entre estudantes.

### Público-alvo

O Juber é destinado principalmente a estudantes universitários, especialmente jovens que precisam se deslocar diariamente ou com frequência até a faculdade.

Persona 1: Passageiro

Estudante que precisa encontrar uma forma prática e acessível de chegar à faculdade.

Suas principais necessidades são:

Encontrar trajetos compatíveis com sua rotina;

Ter maior previsibilidade nos horários;

Reduzir os gastos com transporte;

Encontrar outros estudantes que realizem trajetos semelhantes.

Persona 2: Motorista

Estudante ou pessoa que realiza determinado trajeto até a faculdade e possui vagas disponíveis no veículo.

Suas principais necessidades são:

Encontrar passageiros com trajetos compatíveis;

Compartilhar os custos da viagem;

Organizar os horários dos trajetos;

Utilizar melhor as vagas disponíveis no veículo.

### Como o Juber funciona

A proposta do aplicativo é baseada na conexão entre trajetos, horários e usuários.

De maneira simplificada:

Usuário  
   │  
   ▼  
Cadastro/Login  
   │  
   ▼  
Define origem, destino e horário  
   │  
   ▼  
Sistema procura trajetos compatíveis  
   │  
   ├───────────────┐  
   ▼               ▼  
Passageiro      Motorista  
   │               │  
   └───────┬───────┘  
           ▼  
    Compatibilidade  
           │  
           ▼  
    Compartilhamento  
       do trajeto  

O sistema teria como base informações como:

Local de origem;

Destino;

Dia do trajeto;

Horário;

Número de vagas disponíveis;

Perfil do usuário.

A partir dessas informações, o aplicativo poderia apresentar opções compatíveis entre passageiros e motoristas.

### Principais funcionalidades

Entre as funcionalidades planejadas para o Juber estão:

Cadastro de usuários

Permitir que estudantes criem uma conta e informem seus dados básicos.

Perfil

Cada usuário possui um perfil com informações necessárias para utilização do serviço.

Cadastro de trajetos

O motorista pode informar:

Origem;

Destino;

Data;

Horário;

Quantidade de vagas disponíveis.

Busca de trajetos

O passageiro pode procurar trajetos compatíveis com sua necessidade.

Correspondência entre usuários

O sistema identifica possíveis combinações entre passageiros e motoristas com base nas informações dos trajetos.

Solicitação de vaga

O passageiro pode solicitar uma vaga em um trajeto disponível.

Gerenciamento de viagens

Motoristas e passageiros podem acompanhar os trajetos dos quais participam.

Histórico de viagens;

Sistema de denúncias;

Controle de usuários;

Compartilhamento de informações da viagem;

Recursos para aumentar a segurança durante o trajeto.

### Problema que o projeto busca solucionar

O deslocamento até a universidade pode representar uma dificuldade para muitos estudantes devido a fatores como:

Custo do transporte;

Distância entre residência e faculdade;

Falta de opções de transporte em determinados horários;

Dependência de transporte público;

Tempo gasto no deslocamento;

Vagas ociosas em veículos que já realizariam o trajeto.

O Juber propõe utilizar a economia compartilhada como base para enfrentar parte desses problemas.
